# Frontend

Empty on purpose: the framework is chosen per project. Ask your agent to run the **`init-stack`**
skill (`/init-stack` in Claude Code, `$init-stack` in Codex). It scaffolds Vite + React, Next.js or
Astro here, wires the generated API types and the scripts CI expects, and rewrites this README.

What every framework here must provide is in `AGENTS.md`.
